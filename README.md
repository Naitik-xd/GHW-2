# 🎨 GradeLab — Color Palette Generator

**Find your next look.**

GradeLab is a lightweight, responsive color palette generator built for designers, color graders, and creative minds. Generate fresh color combinations, lock your favorite shades, and copy HEX codes instantly.

## ✨ Features

- 🎨 **Random Palettes** — Generate a fresh palette of five colors.
- 🔒 **Lock Colors** — Keep your favorite colors while generating new combinations.
- 📋 **Copy HEX Codes** — Copy individual color codes with one click.
- 📦 **Copy All** — Copy all five HEX codes at once.
- 🌙 **Dark Interface** — A clean, dark UI inspired by professional creative tools.
- ⌨️ **Keyboard Shortcuts** — Press `Space` to generate a palette and `C` to copy all colors.
- 📱 **Responsive Design** — Works across desktop and mobile screens.
- 🔔 **Instant Feedback** — Get notifications when colors are copied.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Clipboard API

No frameworks, backend, or external dependencies required.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Naitik-xd/GHW-2.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

That's it! Start generating palettes.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Space` | Generate a new palette |
| `C` | Copy all HEX codes |
